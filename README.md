# 2D Game Inspired by the Movie Drive

My first solo 2D action game project, inspired by the movie *Drive*.

## About

A 2D action game project developed as a personal practice and portfolio project.

Approximately 90% of the game's content and development was created by me, including the core gameplay systems, game mechanics, scene design, menu design, dialogues, and overall game structure.

## My Contributions

- Game mechanics and gameplay dynamics
- Scene and level design
- Main menu design
- Game flow and structure
- Dialogues and conversations
- Character animations
- Enemy implementation and gameplay integration
- Overall game development and improvements

Some visual assets, such as backgrounds and the base enemy character, were obtained from existing resources. However, I adapted, modified, and integrated these assets into the game myself.

## Technologies

- Unity
- C#

## Project Type

Personal / Solo Game Development Project
